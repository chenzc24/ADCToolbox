## 已确定的首批范围

本次扩展面向电脑代码中的行为仿真与数字校准，不以已有芯片或硬件实现为前提。
用户确定至少补充以下两部分：

1. **Dither 后台校准仿真**：建立明确的注入路径、可观测误差信息、参数更新与持续跟踪闭环。
2. **前台非线性校准案例**：至少覆盖多项式和神经网络，复用已有研究实验，但提供清楚的训练与应用过程。

本阶段先将分析和计划纳入版本管理。本记录不代表这些功能已经加入正式 API。
TI 后台完善、SAR 后台校准、后台非线性与在线神经网络作为后续候选，不自动扩大首批范围。

## 分类口径

使用两个独立分类轴，组成四个象限：

- **前台／后台**：参数在专门的校准阶段辨识，还是在正常信号转换期间辨识和更新。
- **线性／非线性**：校准参数固定后，校正映射对声明的输入特征是线性／仿射，还是非线性。

固定 bit 位权和线性 FIR 归在线性一侧；多项式、LUT 和非线性神经网络归在非线性一侧。
线性位权能够修正部分 ADC INL/DNL；“线性校准”不意味着只能修正模拟增益和偏置。
多项式可以对待估计系数线性、对输入码值非线性，使用最小二乘不会改变其分类。

静态／带记忆是另一个独立标签。使用上一拍输入不等于后台学习；离线训练后固定权重的
神经网络，即使持续输出校正结果，也不属于后台参数辨识。片上／片外、软件／硬件同样
不决定前台／后台分类。

### 正式前台实现

- [`calibrate_weight_sine`](../../python/src/adctoolbox/calibration/calibrate_weight_sine.py)
  与 [`calibrate_weight_sine_lite`](../../python/src/adctoolbox/calibration/calibrate_weight_sine_lite.py)

- MATLAB [`wcalsin`](../../matlab/src/wcalsin.m) 及其兼容名称不重复计为新算法。
- TI [`extract_mismatch_sine`](../../python/src/adctoolbox/timeinterleave/extract_mismatch_sine.py)

- [`fit_static_nonlin`](../../python/src/adctoolbox/aout/fit_static_nonlin.py)
  提取前向失真系数和传输曲线，尚不是训练后直接校正新数据的完整流程。

### 已有 TI 后台原型及限制

[`exp_ti02_autocorr_background_skew_calibration.py`](../../python/src/adctoolbox/examples/08_time_interleave/exp_ti02_autocorr_background_skew_calibration.py)
已有“输出统计量 → 调节方向 → VDL 码更新 → 新采样”的实际闭环。核心 MAD 更新
不读取真实 skew，也不使用理想输入标签。它是混合信号时序校准的软件行为模型。

但当前实现仍有以下限制：

1. [`TIMultiSampler`](../../python/src/adctoolbox/examples/08_time_interleave/variable_delay_line.py)
   输出连续浮点采样值，未包含 ADC 量化。
2. 每次捕获重建单音时间轴并随机化初相，尚非保持连续时间与相位的业务信号流。
3. 尚未覆盖持续漂移、突变和多类业务输入下的跟踪验证。
4. 最终展示使用历史 SFDR 最好的 `best_trim`。MAD 更新是自适应的，但最终结果
   还包含单音评估条件下的参数选择。通用后台验证应以当前参数或明确的可观测在线
   停止／平均规则为准，历史最优指标仅作独立诊断。
5. 已有 TI 单元与集成测试主要覆盖前台提取和校正，未发现该后台闭环的完整跟踪回归集。
6. 部分注释与执行常量不一致：实际输入约 300 MHz，VDL 步长 10 fs；旧注释提到
   450 MHz、50 fs。后续整理时应同步。

## 已完成实验提供的依据

2026-10-30 的研究实验使用独立重构的 Pipeline 行为模型：五级 2.5-bit stage 与
4-bit backend。五个训练种子，每个种子 400 条 × 8192 点，训练、验证、测试分开。
下面为 0.9 V 峰值下七个测试单音频率的平均，再对五个训练种子求均值和样本标准差。

| 方法 | SNDR，dB | SFDR，dB |
| --- | --- | --- |
| 未校准 | 52.36 | 58.78 |
| 固定参考位权 LS | 58.77 ± 0.07 | 66.84 ± 0.14 |
| 位权加上一拍 FIR | 61.17 ± 0.08 | 66.95 ± 0.07 |
| 最终码字分段线性 | 56.98 ± 0.07 | 64.27 ± 0.35 |
| MLP | 62.46 ± 0.34 | 71.88 ± 1.44 |
| 原图 GCN 独立重构 | 62.63 ± 0.73 | 72.99 ± 1.93 |
| A=I GCN | 62.74 ± 0.11 | 73.06 ± 0.32 |
| 逐级 LUT 加残差多项式和上一拍 | 63.40 ± 0.17 | 73.39 ± 0.57 |

固定参考位权 LS 不等于直接调用现有 `calibrate_weight_sine`：两者的参考估计与
目标不同。实际函数也已单独测试，但仅使用前 20 条单音记录，不能作为主表的同预算排名。
传统模型用平方误差训练，神经网络用 MAE；上述比较是完整方法比较。

机制分离实验表明，记忆误差需要历史信息，码相关 DAC 误差适合逐级 LUT，残差
三次非线性适合相应非线性特征。直接增加静态多项式阶数没有普遍收益。

参考信号诊断中，同样的 20 条单音输入、同一结构化模型，拟合参考训练得到平均
62.52 dB SNDR，仿真理想输入参考得到 65.40 dB。理想输入仅为诊断，不能作为实际
后台算法可获得的学习信号。参考估计与模型能力需要分别评估。

这些结果局限于当前仿真误差模型；结构化基函数与其三次非线性、一阶记忆机制较匹配。
它们支持补充前台非线性案例，不证明真实芯片、其他架构或后台校准具有相同结果。

## 首批实现方案

### Dither 后台仿真

建议以 Pipeline 首级增益误差为第一个对象，先建立可解释的小型闭环。

- 在明确的模拟路径中注入已知 PN 序列，使其经过待辨识的误差机制。
- 校准器只使用输出码、允许访问的子码、已知 PN 和历史估计状态。
- 根据注入结构推导相关估计／更新方程，并实现与之匹配的数字注入分量消除。
- 包含注入幅度、转换余量、过载、量化、残留 PN、步长和平均时间的影响。
- 不把最终数字输出后添加随机数当作模拟注入的替代。
- PN 注入点、归一化和误差观测方程属于实现前必须明确的设计内容，尚未定案。

同一连续输入和漂移器件上，至少比较：未校准、初始前台校准后冻结、持续后台更新。
理想参数校正可以作为明确标注的诊断上界，不能参与实际估计器更新。

### 前台非线性案例

至少实现以下两个代表性案例，并与现有位权基线比较：

1. **多项式校准**：明确输入为最终码字或内部子码；先从低阶模型开始，增加
   必要的交叉项或历史项。区分前向失真拟合与实际逆向／直接校正。
2. **轻量 MLP 校准**：明确输入编码、归一化、参数量、训练预算、参考构造和验证
   选择过程。保留独立测试和冻结参数应用，不自动称为后台校准。

逐级 LUT、残差基函数和短记忆模型作为已有实验支持的扩展候选。GCN 保留为对比
或研究模型，当前不设为默认方案。

### 共用仿真与模型约定

- 分开维护被校准 ADC 的真实参数、校准器可观测输入和仅用于评估的真实输入。
- 明确 `fit`、`apply`、`update`、`reset` 的语义；具体 API 名称待实现设计确定。
- 后台模型保持跨数据块的模拟记忆、上一拍子码、PN 状态、时间索引和估计器状态。
- 当前研究 Pipeline `convert()` 中的 `lfilter` 每次重启状态，独立记录使用预热；
  改为连续后台仿真时必须携带滤波状态，不能原样按块反复调用。
- 明确 `bits`、多 bit stage subcode、最终 ADC code 的区别以及输出尺度。
- 记录有效秩、激励覆盖、训练域及无法辨识的参数；参数数目不直接换算为硬件面积。

## 验收实验

| 场景 | 需要验证的行为 |
| --- | --- |
| 固定误差 | 启动收敛、稳态误差、增加注入后的代价 |
| 缓慢漂移 | 后台跟踪滞后及相对冻结前台模型的收益 |
| 参数突变 | 恢复时间、过冲或发散、保护／冻结策略 |
| 幅度与频谱变化 | 是否将业务信号变化误判为器件变化 |
| 激励不足 | 不可辨识时能否识别并停止不可靠更新 |
| 独立波形 | 单音、双音／多音及调制信号的泛化 |
| 数据块边界 | 连续调用与一次性处理的状态和结果一致性 |

后台指标应按时间窗口报告，不能只用最后一次 FFT。前台案例应分离训练、验证和
测试，并在测试阶段冻结模型。仿真真实输入、真实增益和真实 skew 只进入评估通路。
